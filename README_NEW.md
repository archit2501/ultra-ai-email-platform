### 🎨 **3. 5-Tone Email Generation**

AI generates personalized emails in 5 distinct tones:

#### **Professional Tone**
- **Best For**: Corporate roles, formal industries (finance, consulting)
- **Subject**: "{Title} Interested in Opportunities at {Company}"
- **Style**: Formal, business-appropriate, structured
- **Example Opening**: "I hope this email finds you well. I am writing to express my strong interest in opportunities at {Company}."

#### **Enthusiastic Tone**
- **Best For**: Startups, creative roles, younger companies
- **Subject**: "Thrilled to Apply to {Company}!"
- **Style**: High energy, passionate, engaging
- **Example Opening**: "I'm thrilled to connect with {Company}! I've been following your work on {project} and I'm genuinely impressed."

#### **Story-Driven Tone**
- **Best For**: Personal brands, creative industries
- **Subject**: "My Journey to {Company}"
- **Style**: Narrative-based, relatable, authentic
- **Example Opening**: "Three years ago, I discovered {Company}'s mission of {mission}. Since then, I've been working towards..."

#### **Value-First Tone**
- **Best For**: Consultants, senior roles, value-focused outreach
- **Subject**: "AI/ML Engineer with Published Research - {Name}"
- **Style**: Lead with value, results-oriented
- **Example Opening**: "I specialize in {skill} with {X} years of experience delivering {results}. I noticed {Company} is working on {project}..."

#### **Consultant Tone**
- **Best For**: Freelancers, contractors, consulting roles
- **Subject**: "Partnership Opportunity: {Skill} Expertise"
- **Style**: Expert positioning, collaborative
- **Example Opening**: "As a {title} with expertise in {skills}, I help companies like {Company} achieve {outcome}."

**Personalization Features:**
- Includes specific company projects
- Mentions matched technologies
- References job openings
- Highlights relevant candidate skills
- Adds concrete achievement examples

**Personalization Scoring:**
```
Score Breakdown:
- Skill match strength (0-30 points)
- Company research depth (0-25 points)
- Project relevance (0-20 points)
- Achievement inclusion (0-15 points)
- Custom opening (0-10 points)

Total: 0-100% Personalization Score
```

**How to Use:**
1. Complete research (auto-starts when panel opens)
2. Generate tab → Auto-generates 5 email variations
3. See dropdown with all tones + scores
4. Select tone → Preview appears below
5. Click "Edit & Preview Full Email"
6. Edit subject/body as needed
7. Click "Save Changes" (persists to localStorage)
8. Email saved permanently per recipient

### 📊 **4. Skill Matching Algorithm**

Intelligent skill matching with category-weighted scoring:

**Categories & Weights:**
```
Programming Languages: 25% weight
  - Python, JavaScript, Java, C++, Go, Rust, TypeScript...

Frameworks & Libraries: 20% weight
  - React, Django, TensorFlow, Spring Boot, Express...

Databases: 15% weight
  - PostgreSQL, MongoDB, Redis, MySQL, Cassandra...

Cloud & DevOps: 15% weight
  - AWS, Azure, GCP, Docker, Kubernetes, Terraform...

Tools & Platforms: 10% weight
  - Git, Jenkins, JIRA, VS Code, Postman...

Soft Skills: 10% weight
  - Leadership, Communication, Agile, Problem-solving...

Domain Knowledge: 5% weight
  - Machine Learning, Blockchain, IoT, Security...
```

**Match Strength Levels:**
- **PERFECT** (90-100%): Exceptional fit, all key skills aligned
- **STRONG** (70-89%): Great match, most skills aligned
- **MODERATE** (50-69%): Good fit, core skills present
- **WEAK** (30-49%): Limited match, some skills relevant
- **MINIMAL** (<30%): Poor fit, minimal skill overlap

**Output:**
```json
{
  "match_strength": "STRONG",
  "overall_score": 85,
  "matched_skills": ["Python", "React", "PostgreSQL", "AWS"],
  "category_scores": {
    "languages": 90,
    "frameworks": 85,
    "databases": 80
  },
  "talking_points": [
    "Your experience with Python and TensorFlow aligns perfectly with our ML initiatives",
    "React expertise matches our frontend tech stack"
  ]
}
```

### **Request Flow: ULTRA AI Email Generation**

```
User Action: Click Recipient Row
          ↓
1. UltraEmailPanel Opens (slide-in animation)
          ↓
2. Research Tab Auto-Starts
   - POST /api/v1/recipients/{id}/research
   - Scrape 10+ pages (homepage, about, careers, blog, GitHub)
   - Extract: tech_stack, jobs, projects, culture, news
   - Calculate confidence score
   - Cache for 30 days
   - Show progress: 0% → 90% → 100%
          ↓
3. Generation Tab Auto-Starts
   - POST /api/v1/recipients/{id}/generate-emails
   - Load candidate resume (from candidate.skills)
   - Perform skill matching
   - Generate 5 email variations:
     * Professional (formal, structured)
     * Enthusiastic (high energy)
     * Story-Driven (narrative)
     * Value-First (results-focused)
     * Consultant (expert positioning)
   - Calculate personalization scores (0-100%)
   - Estimate response rates (8-13%)
   - Show progress: 0% → 90% → 100%
          ↓
4. User Selects Tone
   - Dropdown selector or quick comparison list
   - Preview shows: subject, body excerpt, score, matched skills
   - Click "Edit & Preview Full Email"
          ↓
5. Preview Tab Opens
   - Split view: Email Editor (2/3) | Analytics Sidebar (1/3)
   - Edit subject and body
   - See real-time stats: word count, reading time
   - Save changes → localStorage persistence
          ↓
6. Email Saved
   - Saved to localStorage: saved-emails-{recipient.id}
   - Persists across panel opens/closes
   - Load saved version on next tone selection
```

## 📦 Installation

### **Prerequisites**

```bash
# Required
- Node.js 18+ (Frontend)
- Python 3.10+ (Backend)
- Git

# Optional
- PostgreSQL 14+ (Production)
- Redis (Caching - optional)
```

### **Quick Start (Development)**

#### **1. Clone Repository**
```bash
git clone <repository-url>
cd hr-resume-web-app
```

#### **2. Backend Setup**
```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Create .env file
copy .env.example .env
# Edit .env with your settings

# Run database migrations
alembic upgrade head

# Start development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend runs on: **http://localhost:8000**

#### **3. Frontend Setup**
```bash
cd frontend

# Install dependencies
npm install

# Create .env.local file
copy .env.example .env.local
# Edit .env.local with your settings

# Start development server
npm run dev
```

Frontend runs on: **http://localhost:3000**
